## 프로젝트 소개

> 질문의 부담은 낮추고, 질문과 답변을 저장하고 공유하며, 잊혀진 소통 방식을 되살리는 서비스.

강의 중 놓친 설명을 개인 노트에 적고, 궁금한 내용을 별도 게시판에 질문하면 강의자료와 학습 기록이 서로 떨어지기 쉽습니다. 같은 내용을 궁금해하는 학생들이 있어도 질문과 답변이 강의실 안에서 일회성으로 끝나기도 합니다.

**TikiTaka는 강의자료를 중심으로 교수자의 실시간 필기, 학생의 개인 필기, 위치 기반 질문과 답변을 연결합니다.** 강의 중의 소통을 기록으로 남기고, 강의 이후에는 복습할 수 있는 학습 아카이브로 활용합니다.

| 해결하고자 하는 문제 | TikiTaka의 접근 |
| --- | --- |
| 설명을 듣고 교수자의 필기를 따로 옮겨 적어야 하는 부담 | 교수자의 필기를 학생 화면에 실시간 공유 |
| 질문이 강의자료의 어느 부분에 관한 것인지 설명하기 어려움 | 슬라이드의 특정 위치와 질문 연결 |
| 개인 필기와 공동 학습 기록이 뒤섞임 | 공유 필기와 개인 필기를 별도 레이어로 관리 |
| 강의 중 오간 질문과 답변이 사라짐 | 자료와 연결된 질문·답변 아카이브 제공 |
| 자료·공지·과제 확인을 위해 여러 도구를 오가야 함 | 강의 공간을 중심으로 학습 활동 통합 |

## 주요 기능

### 1. 강의 공간 생성 및 참여

- 강의별 Space를 생성하고 참여 코드로 학생을 초대합니다.
- 강의자료, 공지, 과제, 질문을 하나의 강의 공간에서 관리합니다.
- 교수·조교·학생 역할과 조교에게 위임한 권한에 따라 이용 범위를 구분합니다.

### 2. 슬라이드 기반 실시간 필기 공유

- PDF 강의자료를 슬라이드 단위로 확인하며 필기합니다.
- 교수자의 공유 필기를 WebSocket으로 학생 화면에 전달합니다.
- 필기 데이터를 저장해 강의 이후에도 다시 조회할 수 있습니다.

### 3. 학생 개인 필기

- 교수자의 공유 필기와 별도로 학생 자신의 필기를 작성합니다.
- 슬라이드별 개인 필기를 저장하고 다시 불러옵니다.
- 공유 내용과 개인 학습 기록을 함께 보며 복습할 수 있습니다.

### 4. 슬라이드 위치 기반 질문과 답변

- 강의자료의 궁금한 위치에 질문을 남깁니다.
- 질문을 자료·슬라이드와 연결해 질문이 발생한 맥락을 유지합니다.
- 교수자는 질문을 확인하고 답변을 작성하며, 학생은 기존 질문과 답변을 다시 확인합니다.

### 5. 질문 아카이브

- 강의 중 생성된 질문과 답변을 강의 이후에도 조회합니다.
- 강의자료별 질문을 모아 확인하고 필요한 내용을 검색합니다.
- 다른 학생의 질문과 답변도 복습 자료로 활용합니다.

### 6. 강의 운영 통합 관리

- 강의 공지와 과제를 관리합니다.
- 시간표와 과제 마감일을 확인합니다.
- 강의 참여자 및 참여 요청을 관리합니다.

### AI·음성 처리 연계

질문 아카이브의 탐색과 답변 기록을 보완하기 위해 다음 기능을 설계했습니다. 아래 항목의 구현·배포 상태는 각 서비스 저장소에서 관리합니다.

| 기능 | 처리 방향 |
| --- | --- |
| 유사 질문 그룹화 | 질문을 임베딩하고 유사한 질문을 묶어 탐색 지원 |
| 질문 정제 및 그룹 요약 | 질문 표현을 정리하고 그룹의 주제를 대표하는 제목 제공 |
| 음성 답변 기록 | 음성 답변을 저장하고 STT로 텍스트 기록 지원 |

## 핵심 설계

### 공유 필기와 개인 필기 분리

슬라이드에 표시되는 교수자의 필기와 학생 자신의 필기를 분리해 관리합니다. 공유 필기는 강의 참여자에게 전달하고, 개인 필기는 작성자에게 연결해 저장합니다.

### 필기 전송과 영속 저장

실시간 메시지는 강의 중 다른 사용자의 화면을 갱신하는 데 사용하고, 저장된 필기 데이터는 이후 조회와 복습에 사용합니다. 빠른 필기에서 저장 요청이 과도하게 누적되지 않도록 프론트엔드의 적응형 묶음 전송을 적용했습니다.

### 자료와 질문의 맥락 연결

질문을 강의자료·슬라이드·위치 정보와 연결해 관리합니다. 질문 목록에서 답변을 찾은 뒤에도 어떤 자료의 어느 부분에서 나온 질문인지 확인할 수 있습니다.

### 역할과 위임 권한

| 역할 | 권한 범위 |
| --- | --- |
| 교수 | 강의 공간 운영 및 권한 관리 |
| 조교 | 교수가 위임한 멤버·자료·공지·질문·과제 관리 권한 |
| 학생 | 참여 강의의 공개 자료 이용, 개인 필기 및 질문, 과제 참여 |

API 설계에서는 역할뿐 아니라 강의 참여 승인 상태와 조교의 개별 권한을 함께 검증합니다.
